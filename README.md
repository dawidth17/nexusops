# NexusOps

NexusOps is a personal project for learning and practicing software development, Linux, DevOps and infrastructure technologies.

The goal is to build an IT operations platform step by step using several languages and technologies.

## Components

- ServiceCore - Java / Spring Boot
- OpsSight - Python / FastAPI
- SentinelAgent - C/C++
- Console - React / TypeScript

## Main technologies

- Java 21
- Python 3.12+
- C / C++
- React / TypeScript
- PostgreSQL
- Docker
- Kafka
- Prometheus / Grafana

More technologies will be added as the project progresses.
